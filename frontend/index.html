Quick Reference Guide

This dashboard provides access to local files and Ollama setup guides. Ensure you've followed these setup protocols:

  • Run ollama pull gpt-oss in your terminal.
  • Run ollama pull nomic-embed-text for RAG embeddings.
  • Verify Ollama status dot turns green in the upper-right corner.
  • Drop PDFs or Markdown notes in c:\sentinalai\data\raw_datasets and run a scan to enrich the threat database.
